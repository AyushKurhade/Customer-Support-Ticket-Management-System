# Customer Support Ticket Management System

## Project Type
DBMS Mini Project

## Domain
IT Services

## Objective
To develop a database-driven customer support ticket management system
for creating, categorizing, assigning, tracking, and resolving support tickets.

## Main Components

1. Login/User Management
2. Master Data Management
3. Ticket/Activity Management
4. Search & Filter
5. SQL Queries & Joins
6. Reports & Dashboard
7. AI/DS Analysis
8. Database Concepts
